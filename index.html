Lab Limit

Aplikasi Limit · SMAN 2 Tasikmalaya

Halo! Aku Limo. Isi data dulu, lalu kita dekati nilai limit bersama-sama.

1. Apa itu limit?

Limit adalah nilai yang didekati fungsi ketika variabel mendekati titik tertentu, tanpa harus sama dengan titik itu.

limx→c f(x) = L   (f(x) mendekati L saat x mendekati c, x ≠ c)

Contoh: f(x) = x2 − 1x − 1 tidak terdefinisi di x = 1, tetapi nilainya mendekati 2.

x0,90,990,9991,0011,011,1
f(x)1,91,991,9992,0012,012,1

Dari kiri dan kanan hasilnya sama-sama menuju 2, jadi limx→1 f(x) = 2. Limit ada jika limit kiri = limit kanan:

limx→c− f(x) = limx→c+ f(x)

2. Langkah menentukan limit fungsi aljabar

  1. Substitusi langsung x = c ke f(x).
  2. Jika hasilnya bilangan biasa, itulah limitnya.
  3. Jika hasilnya 00 (bentuk tak tentu), sederhanakan dulu: faktorkan pembilang dan penyebut, atau kalikan akar sekawan.
  4. Coret faktor yang sama (boleh, karena x ≠ c), lalu substitusi lagi.
limx→4 x2 − 16x − 4 = limx→4 (x − 4)(x + 4)x − 4 = limx→4 (x + 4) = 8

Jika pembilang tidak nol tetapi penyebut nol (mis. 50), nilai fungsi membesar tanpa batas, sehingga limitnya tidak ada (menuju ±∞).

3. Limit tak hingga

Saat x → ∞ gunakan fakta: 1x → 0 dan e−x → 0.

limx→∞ 10001 + e−x = 10001 + 0 = 1000

4. Limit trigonometri

limx→0 sin xx = 1

Substitusi langsung memberi 00, tetapi tabel dan grafik menunjukkan nilainya mendekati 1. Coba di tab Grafik interaktif. Limit ini adalah dasar turunan trigonometri.

5. Limit dalam kehidupan nyata

  • Fisika: kecepatan sesaat = limit kecepatan rata-rata saat selang waktu mendekati 0.
  • Biologi: populasi mendekati kapasitas maksimum lingkungan.
  • Ekonomi: keuntungan mendekati nilai tertentu saat produksi mendekati titik tertentu.
  • Teknologi: kecepatan unduhan rata-rata saat kuota mendekati batas paket data.

Limit adalah fondasi turunan dan integral, materi berikutnya.
